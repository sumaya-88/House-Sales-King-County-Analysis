markdown# 🏠 House Sales Price Prediction - King County, USA

## 📌 Project Overview
This project analyzes and predicts house sale prices in King County, USA (including Seattle) using machine learning. Built as the final capstone project for the **IBM Data Analysis with Python** course on Coursera.

## 📊 Dataset
- Houses sold between May 2014 and May 2015
- 21 features including bedrooms, bathrooms, sqft_living, waterfront, grade, etc.
- Target variable: **price**

## 🛠️ Technologies Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## 📋 Project Modules
1. **Data Importing** - Load and explore the dataset
2. **Data Wrangling** - Handle missing values, drop irrelevant columns
3. **Exploratory Data Analysis** - Visualizations and correlations
4. **Model Development** - Linear & Multiple Regression
5. **Model Evaluation** - Ridge Regression, Polynomial Features, R² scoring

## 📈 Key Results
| Model | R² Score |
|-------|----------|
| Simple Linear Regression (sqft_living) | ~0.49 |
| Multiple Linear Regression | ~0.65 |
| Pipeline (Polynomial + Scaling) | ~0.75 |
| Ridge Regression | ~0.65 |
| Ridge + Polynomial Features | ~0.70 |
